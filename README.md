TABTIDY is a simple chrome extenstion for managing browser tabs.
it helps find tabs, close the ones you don't need, save browsing sessions and restore them later.

I built it with:
CSS
HTML
Javascript (JS)
Chrome Extensions API

To Install it:
1. Clone this REPO
2. Open chrome://extensions in Chrome
3. Enable developer mode
4. Click load unpacked
5. Select the TABTIDY project folder
